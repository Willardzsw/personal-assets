# 自用 TVBOX / OK影视源

配置地址（填入 OK影视的点播配置地址）：

```text
https://raw.githubusercontent.com/Willardzsw/TVBOX/main/config.json
```

本仓库独立保存主配置及 72 个依赖快照，当前保留 78 个站点入口、10 组直播列表。点播入口包含影视、网盘、音乐、学习和工具，并非全部是视频网站。

## 使用

在 OK影视设置中打开配置地址，填入上面的 Raw 链接并刷新。然后测试一个站点的分类、搜索、详情和播放，再切到直播页测试频道。不同版本菜单名称可能不同。电视所在网络必须能访问 GitHub Raw。

本次只验证文件、配置和公开下载，不代表这些站点或电视流已逐个播放成功。

## 已经独立保存的部分

- `config.json`：主配置，插件与规则的直接引用已指向本仓库。
- `vendor/one/`：从原仓库历史提交保存的脚本、规则和直播列表。
- `vendor/external/`：原配置引用的外部 JAR、脚本、规则及直播列表快照。
- `sources.json`：每个文件的来源、大小与 SHA-256，原文件版权归原作者。
- `tools/verify.py`：检查文件完整性、仓库路径和已知凭据特征。

这不是 Fork；原仓库关闭不会删除这些已经复制的文件。主配置和已保存文本中的可识别原仓库文件引用已经替换。不要把账户、Cookie、Token、密码或完整私钥放进公开仓库，网盘授权在自己的客户端中设置。

## 仍然存在的依赖和限制

- 视频网站、网盘、在线解析接口、实际直播流仍由外部服务提供；网站关闭或接口变化时需要更新规则。
- JAR 二进制保持原样，部分内置更新、原生库或辅助服务下载地址仍指向第三方，尚未完成 Android 运行时验证。备份主配置不等于消除所有运行时网络依赖。
- 无法获取或包含硬编码私钥材料的脚本没有放入本仓库。一个上游账户访问令牌已从保存的脚本中清空，其站点入口也已移除。
- 直播列表是快照，带时效的地址可能过期。清单数量不等于可播放频道数量。

本次未启用的原站点：Acfun, csp_Guazi, csp_douyu, csp_huya, hxq, wawa, 咕噜咕噜, 山楂, 星河, 极影, 爱看剧。完整的静态分析限制见 [迁移说明](MIGRATION.md)。

## 自己维护

1. `sites` 中删除整个站点对象可移除入口，调整数组顺序可排序；保留站点的 `api`、`ext`、`jar` 对应关系。
2. `lives` 保存直播列表入口，列表文件已在本仓库；更换频道时编辑对应快照。
3. 修改文件后运行 `python tools/verify.py`。若有意修改依赖，更新 `sources.json` 中该文件的 SHA-256，再运行检查。
4. 先在客户端测试，再保留一份已知可用的提交。不要无差别自动同步上游覆盖自用版本。
